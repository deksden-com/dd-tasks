# Consolidation

Read the frozen shared coordinator contract, actual input history and accepted
interactive predecessor. Reconstruct implemented facts and entry-relative patch,
separating pre-existing changes, rejected ideas, plans and unknowns. Reassess scope
against explicit finish and all prior constraints. Resolve original selected Git
inclusion now, before independent review freezes the task. Do not overwrite
divergent staged bytes or turn finish into approval.

Define substantive hardening/check obligations for the actual patch, including
project policy checks and durable documentation updates. Do not launch a custom
pipeline or perform Git effects. Propose the consolidated change_summary and
current limitations, then use issued finish.
