# Integration

its exact change_summary and inherited limitations. Call `interactive integrate`
for this RUN. Required original-input inclusion agreement cites genuine user
input already resolved before review and exact selected paths. Do not invent
approval, ask a new question and reuse stale review, or widen scope.

history. Never push, stash/reset, commit other paths or repeat an unknown effect.

requires terminal Stage and RUN closure, including recovery if only acceptance
committed. Final response reports actual changes/checks/integration/limitations;
do not claim release, publication or cleanup that did not happen.
