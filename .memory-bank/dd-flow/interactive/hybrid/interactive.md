# Interactive work

Read the frozen shared coordinator contract and accepted preflight. Work with
the user on the actual task, without a replacement formal specification.
Retain verbatim turns and actual HITL answers; reassess scope before every new
path or changed requirement. Preserve original dirty/staged bytes and unrelated
work. Make only applicable agreed edits; record meaningful rationale/uncertainty,
not a duplicate Git log. Do not commit, merge or silently create another RUN.

Without an explicit retained finish request keep this Stage open using ordinary
pause/continuation. A quiet terminal, observer disconnect, ACK or the word finish
inside quoted text is not consent. Once explicit finish is retained, reassess
scope and propose the actual accumulated change summary. Completion does not
claim hardening, review or successful tests; consolidation follows.
