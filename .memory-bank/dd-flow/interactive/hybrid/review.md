# Independent review

Read the frozen shared coordinator contract, accepted hardening and current task/
scope. Register initial critic with `interactive register --stage review`, then
use its genuine physical read-only Work route. Review substantive task,
preservation and correctness risks, not formatting tastes. The critic must not
edit source or become the correction author.

Execute current review checks and use actual settled critic results. Negative
review keeps this Stage/attempt open. Register correction from that exact Work,
settle its separate author, rerun checks and register fresh re-review from the
exact correction Work. Preserve issue history; the independent critic reassesses
every pending issue against this patch. No old pass after source/task drift,
Stage rewind or synthetic approval.

Propose summary/change_summary/limitations only; the handler derives accept/revise.
Resolve necessary new user decisions honestly: they invalidate prior scope/
readiness and cannot be smuggled directly into integration.
