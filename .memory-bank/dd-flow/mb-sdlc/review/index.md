# Project review criteria

Execution belongs to `dd-flow review` and the registered hybrid stages from
the selected global canon, not this project-pack reference index.

- [Baseline aspects](aspects.md): each receives explicit applicability/reason,
  source evidence and limitations.
- [Universal critic](critics/universal.md): independently assesses every candidate.
- [Architecture critic](critics/architectural-harmonization.md): applies when
  architecture harmonization is applicable.
- [Retained report template](stage-report-template.html): historical report reader
  support, not the schema or publication authority for a new hybrid RUN.

CLI owns assigned Work and separate critic Sessions; reference route labels
do not authorize self-review in place of required independence, local dispatch,
manual report acceptance or repair. Rejected/downgraded candidates, duplicates
and disagreements remain traceable. JSON is authoritative; current Markdown/HTML
reports are CLI-owned projections in RUN home, not project dashboard writes.
Recommendations and proposed DEFs are runtime data, not accepted repair scope.
