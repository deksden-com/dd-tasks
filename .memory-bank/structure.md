# Структура Банка памяти

Активные полки: spec/product, spec/system, spec/engineering, spec/operations и protocol. Они содержат только подтверждённые факты checkpoint-00-initial.

adr, plans, scenarios, evidence, ui, guides, skills, defs и archive существуют как канонические полки. Они не получают развёрнутые документы без самостоятельных подтверждённых сведений.

mbb — копия MBB 2.14.1. dd-flow — curated project-local pack; canonical-only mb-init, mb-upgrade и mb-distill не установлены.
